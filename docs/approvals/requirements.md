# 需求：管理系統第三期表單簽核

版本：v1.1 / 2026-10-18（Eason 已確認；門檻改為後台可編輯）
落點：鼎兆元管理系統（~/dzy）新模組，共用 DZY 帳號登入；後端在 Mac mini（dzy-platform）。
來源：10 題 Eason 2026-10-18 回「照推薦」（題目與探到的事實見 `questions.md`）。

## 1. 要解決的問題
跟錢和人有關的申請（買東西、報帳、離職調職調薪）現在靠口頭、LINE、紙本，
事後查不到「誰在什麼時候同意的」，簽完也沒人追「錢撥了沒、手續辦了沒」。
打卡系統已經處理加班、請假、忘打卡、出差（值班主管一層核准），這期**不重做**那四種。

## 2. 使用者
| 角色 | 做什麼 |
|---|---|
| 送件人（已開通 DZY 帳號的同仁，主要是店長、主管） | 填單、附照片、看進度、被退回後修改再送 |
| 簽核人（往上各層主管） | 首頁看到「待我簽」，核准或退回（退回要寫原因） |
| 承辦部門（財務、採購、人資） | 簽完的單出現在部門待辦，辦完按「已處理」結案 |
| 人資、admin | 看全部、處理卡關（改派簽核人） |
| Eason | 每天一則彙整：卡超過 3 天的單 |

## 3. 第一批三種表單（第 1 題）
| 表單 | 主要欄位 | 照片 | 簽完交給 |
|---|---|---|---|
| 請購單 | 單位、品項明細（品名／數量／單位／預估單價，自動加總）、建議廠商、用途、需要日期 | 報價單（選填） | 採購部 |
| 費用請款單 | 單位、費用日期、費用類別、金額、說明、付款對象（還給代墊的人／付給廠商）、對應請購單（選填） | 收據（**必附**至少 1 張） | 財務部 |
| 人事異動單 | 對象同仁、類型（離職／調職／調薪）、生效日、異動前→異動後（單位／職稱／薪資）、原因 | 不用 | 人資部 |

- 欄位第一版寫死，不做「自己設計表單」（第 9 題）。
- 離職單要**同仁本人手寫簽名**（用現成簽名板）；其他單按「核准」就算，系統記誰、幾點（第 6 題）。

## 4. 誰簽（第 2 題；2026-10-18 改為核決權限表）
- 請購、請款依金額決定由誰簽。**權限表不寫死**：後台有一頁「核決權限設定」（2026-10-18 Eason 指定）——
  - 每一列＝「金額到多少」＋「門市權限人」＋「總部權限人」，數字和職級都能直接改；
  - 可以按「新增一級」加一列（例如加「10 萬以上給董事長」），也能刪列；最後一列固定是「以上全部」；
  - 請購、請款共用同一張表（Eason 2026-10-18）；
  - 只有 admin（Eason）能改，每次修改記下誰、幾點、改前改後；已經送出的單照送出當下的門檻走，不會中途變路線。
- **只給權限人簽一關**（2026-10-18 Eason 給「門店支出」核決權限表＋選「只給權限人簽」），上線預設值：

| 金額 | 門市權限人 | 總部權限人 |
|---|---|---|
| 0～5,000 | 店長 | 部門主管 |
| 5,001～10,000 | 營運主管＝該品牌辦公室總監 | 部門主管（暫定） |
| 10,001～30,000 | 總經理 | 總經理 |
| 30,001 以上 | 董事長 | 董事長 |
- 權限人空缺或就是送件人自己 → 往更高一級的權限人。
- 人事異動：對象同仁的上一層主管 → 人資承辦；調薪一律由總經理簽。
- 送件人自己不能簽自己的單。

## 5. 簽完之後（第 3、10 題）
- 最後一關簽完 → 進承辦部門待辦 → 承辦按「已處理」（可寫備註，例如「10/20 已匯款」）→ 結案，送件人看得到。
- 看得到的人：送件人、簽過的人、承辦部門、人資、admin。
- 財務每月可匯出當月請款／請購 Excel 對帳。

## 6. 通知與卡關（第 4、7、8 題）
- 管理系統首頁出現「待我簽 N 張」「待我辦 N 張」（用現有首頁提醒機制）。
- 每天一則彙整給 Eason：卡超過 3 天沒動的單（打算接現有「通知匣」每天 10:00 那則，不另開 LINE 帳號）。
- 3 天沒動：首頁那張變紅。不自動跳關。
- 那一層沒人（空缺、或帳號沒開通）→ 自動往上一層找人；不做代理人設定。往上也找不到 → 交給人資處理。
- 主管個人 LINE 私訊：第二版。

## 7. 照片（第 5 題）
- 管理系統目前不能上傳檔案，這期新做；照片存公司 Mac mini，跟每天備份一起備。
- 手機拍照直接上傳，系統自動壓縮。

## 8. 探到的事實
見 `questions.md`「探到的事實」表。重點：打卡已有四種申請不重做；管理系統無推播、無上傳（要新做）；簽名板、首頁提醒可直接用。

## 9. 上線大前提
2026-10-18 時 128 位同仁只 1 位開通帳號。沒開通＝送不了、也簽不了（簽核人沒開通會被當成「那層沒人」往上跳）。
建議：開發期間同步推店長、品牌總監、總經理、董事長、財務、採購、人資先認領帳號。

## 10. 這期不做
加班／請假／忘打卡／出差（打卡系統已有）、調撥（門市營運系統已有）、自己設計表單、代理人、主管 LINE 私訊、
報修／預支薪資／新人錄用／獎懲（之後再加）、跟損益系統自動連動（請款金額先只匯出 Excel）。

## 11. 驗收（每項都要能打勾）
1. 三種表單都能從手機送出，請款沒附收據送不出去。
2. 用第 4 節權限表每一列各送一張實跑，都只有該列的權限人簽一關。
3. 退回 → 送件人改完再送 → 從第一關重新簽。
4. 空缺層自動往上；自己不能簽自己。
5. 承辦按已處理 → 結案，送件人看得到。
6. 金額門檻設定頁：改數字、新增一級、刪一級後，新送的單走新路線；已送出的單路線不變；非 admin 打開或直接打後端都改不了。
7. 首頁「待我簽」數字正確；卡 3 天變紅並進 Eason 彙整。
8. 財務匯出當月 Excel，金額加總跟畫面一致。
9. 沒權限的人看不到別人的單（直接打後端也拿不到）。
