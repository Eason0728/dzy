# 需求：鼎兆元組織架構改版（requirements）

- 日期：2026-10-14　狀態：等 Eason 確認（網頁版確認頁 `requirements-confirm.html`）
- 前情：組織架構與審核原則已於 2026-10-14 定案（記憶 `dzy-org-structure-2026-10`，確認頁 `../personnel/org-structure-confirm.html`）。本案＝把定案落進管理系統（dzy）與吃同一份組織資料的系統。

## 1. 要解決的問題
管理系統現在的組織是「五個品牌並排＋三個總部（鼎兆元／墨竹亭／小辛辣）」，主管只能審自己那一家店的人。
定案後的組織是一棵樹：鼎兆元總部 › 9 部門；其中營運部 › 三品牌 › 門市。系統不改，之後第二期（職稱鎖系統）、第三期（表單往上簽核）都沒有正確的組織可依。

## 2. 使用者
- 人資：維護同仁的單位、主要部門、兼任部門；審任何人。
- 店長以上／品牌督導／品牌總監／部門主管：審底下的人。
- 全體同仁：認領帳號時選單位與部門；佈告欄依單位分組看公告。

## 3. 核心功能（已定案部分，直接照做）
1. 總部部門＝人資、工程、加盟招商、資訊、行銷、財務、採購、營運、中央工廠（9 個）。
2. 營運部底下三品牌：麻的小辛辣（新竹光復）、墨竹亭（新竹金山、新竹光復、台北六張犁）、一悟燒肉（新竹金山、竹北文興）。
3. 墨竹亭文心／瑞光／美村停用不刪（小辛辣美村／南昌系統裡本來就沒有，不用動）。
4. 每人一個主要部門＋零到多個兼任部門；審核只看主要部門。
5. 審核往上一層：門市同仁→該店店長以上（含該品牌督導／品牌總監）；品牌層→營運部主管；部門同仁→部門主管；部門主管→執行長以上；人資全可審；被審的人職級比審核者高→轉人資。
