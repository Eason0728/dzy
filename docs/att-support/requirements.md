# 支援打卡誰來核（需求 v0.1，2026-10-26，等 Eason 確認）

Eason 原話：「在其他門市有打卡紀錄的話應該是要讓其他門市的主管核定才對，因為原店主管並不知道同仁在其他門市實際的上下班時間。」

## 要 Eason 回答的題目（每題標推薦）
1. 怎麼算「在別家店打卡」？
   - A（推薦）打卡那家店不是他自己的單位就算，不看打卡帳號標的是主店還是支援。
   - B 只看打卡帳號標示為「支援」的。
2. 在支援那家店送的加班單、請假單、忘刷單誰核？
   - A（推薦）跟工時一樣，打卡那家店的店長（央廚＝廠長）。
   - B 仍照原單位的規則。
3. 打卡那家店沒有店長（空缺）時誰核？
   - A（推薦）那家店的上一層：同店區經理 → 該區區督導 → 品牌總監；央廚沒有廠長 → 廚藝總監。人資主管、管理員一律可核。
   - B 回到原單位主管代核。
   - C 只有人資主管、管理員。
4. 原單位主管還要看得到同仁在別店的工時嗎？
   - A（推薦）不用：選單不會因此多出那家店。
   - B 可以唯讀看。
5. 總部同仁到門市打卡（例如資訊部同仁去門市幫忙）？
   - A（推薦）一樣交給那家門市店長核。
   - B 仍由部門總監核。
6. 什麼時候開始？
   - A（推薦）上線當下起，所有還沒核的支援打卡與申請都改給打卡那家店（含上線前幾天還沒核的）。
   - B 只從指定日期之後的打卡開始。
7. 你本人（總部總監）要不要在小辛辣光復有考勤？照新規則，你很可能一家店都沒有。
   - A（推薦）要，只看：新增「指定門市只看考勤」的個別例外，由管理員在權限設定給。
   - B 要，而且能核。
   - C 不用。

## 規則（照推薦）
- 一筆打卡、一張申請，由「打卡那家店」的主管核：門市＝店長，央廚＝廠長。
- 在自己單位打卡：完全照現行兩張表（docs/org/spec.md §15.1），不變。
- 支援店沒有店長：依題 3。
- 督導／總監「只看」：依打卡店屬於哪個品牌、哪個區，不依人屬於哪個品牌。
- 總部打卡（hq）：照那位同仁原本的規則，不變（總部沒有店長）。

## 例子（現在 → 改後）
| 情況 | 現在誰核 | 改後誰核 |
|---|---|---|
| 小辛辣光復計時同仁去墨竹亭光復支援 | 小辛辣光復店長 | 墨竹亭光復店長 |
| 光復店長本人去金山支援 | 工時：光復店長自己；申請：區經理／區督導 | 金山店長（工時與申請） |
| 資訊部同仁去光復幫忙打卡 | 資訊部總監 | 光復店長 |
| 央廚同仁去門市支援／門市同仁去央廚 | 原單位主管 | 門市店長／廠長 |
| 在自己店打卡 | 自己店長 | 不變 |

## 誰的畫面會變
- 原單位主管：考勤管理選單不再因為底下同仁去別店支援而多出那家店。
- 支援店店長：核定名單多出來支援的人，旁邊標「支援」與原單位。
- 墨竹亭的督導／總監：看得到小辛辣同仁在墨竹亭的支援打卡；小辛辣的督導／總監不再看到自己同仁在墨竹亭的打卡。

## 不變
薪資照人合計所有店的時數；打卡方式；本單位同仁的核定規則；誰能進考勤管理的條件。

## 會動到哪裡（確認後才做）

- 營運系統出勤核定：支援的人旁邊標「支援（原單位）」。
