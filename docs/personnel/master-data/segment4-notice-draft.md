從 ○/○ 起，**新同仁、離職都改在「鼎兆元管理系統」處理**，打卡那邊會自動跟著改，不用兩邊各做一次：

1️⃣ **新同仁**：管理系統 → 同仁名單 → 新增（填姓名、職稱、到職日、手機）
　→ 大約 1 分鐘後，畫面會出現他的打卡編號和打卡連結，當天就能打卡。

2️⃣ **離職**：同仁名單 → 點那位同仁 → 登記離職（填最後上班日）
　→ 最後上班日的隔天凌晨，打卡會自動停用。登記錯了，當天可以撤銷。

3️⃣ **跨店支援**：同仁第一次去別家店支援，用 LINE 打卡時系統會自動把他加進那家店的名冊，
　打卡畫面會請他跟當班主管說一聲。如果他根本不是來支援的，在值班核定頁按「不是本店支援，移除」就好。

⚠ 打卡系統「值班核定」裡原本的「新增同仁」按鈕之後會停用，請改用管理系統。
