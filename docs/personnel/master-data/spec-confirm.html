鼎兆元管理系統・員工名單統一・規格請確認

系統會怎麼動：一張待辦單串起管理系統和六家打卡

需求你已經確認了。這份講「做出來每個畫面、每個時間點會發生什麼事」。看完沒問題回「規格 OK」，我就拆工作開始做。

只有 2 題 都有推薦，照推薦回「規格 OK」即可

1. 店長忘了登記離職，最多可以往回補幾天？

7 天不限

例：阿明 10/20 就沒來了，店長 10/25 才想起來，可以補填 10/20，當晚 00:10 打卡就停。超過 7 天要找總部，避免有人事後亂改離職日影響薪資。

2. 「LINE 自動加進新店」之後，這個人如果在那家店離職過，又跑回去打卡？

不自動加回，請主管處理自動恢復

被停用通常有原因（例如主管刻意移掉）。自動恢復會讓那個決定失效。

整體怎麼串

店長在管理系統按新增→管理系統寫一張「待辦單」→Mac mini 上的同步程式每分鐘撿單→打給那家店的打卡系統建人→結果回填，店長畫面顯示打卡連結

為什麼要待辦單：打卡系統偶爾會慢或連不上。有待辦單，失敗了會自己重試（1 分、5 分、30 分鐘後），三次都不行才在首頁亮紅燈，不會有人默默打不了卡。

每個情境會發生什麼

情境誰做結果
新人報到店長填姓名、職稱、到職日、手機拿到 DZY 編號；大約 1 分鐘內主店打卡多一筆，畫面出現打卡編號和「顯示打卡連結」按鈕
離職店長填最後上班日（可以提早登記）最後上班日過完的 00:10，管理系統帳號、每一家打卡都停；名單顯示「打卡已停 3/3」
第一次去別家支援員工自己用 LINE 打卡定位在那家、他在別家已綁 LINE 且在職 → 自動加進那家名冊並打卡；那家值班核定頁標「首次支援」
第一次建對照總部按一次，店長逐一確認系統先用姓名配好，店長在「我的資料 → 待審核 → 打卡對照」按「對／不對」；不對的轉總部
每天 00:10自動拉六家打卡名冊，更新誰在哪家打過卡；有對不上的放首頁「待辦與異常」
佈告欄自動改從管理系統拿名單；「打卡同步」按鈕和跨店主店判定表拿掉。同仁 LINE 自動登入照舊

LINE 自動加進新店：什麼時候「不會」自動加

  • 那家名冊上已經有同名的人 → 照現在的做法，帶出名字請本人確認
  • 他的 LINE 在別家綁的名字不只一個 → 不猜，請主管加
  • 他在那家離職過（看第 2 題）
  • 用各店的專屬打卡連結 → 做不到，第一次跨店一定要用 LINE 打卡

首頁「待辦與異常」會多出這些

  • 某人打卡沒建成功／停用沒成功（可按重試）
  • 打卡名冊上有人、但管理系統對不到（例：有人還在用值班核定的舊新增按鈕）
  • 管理系統已離職、某家打卡還在職
  • 還有幾筆對照等店長確認

連續 7 天這區是空的，就算這一期成功。

不會變的

  • 打卡、裝置綁定、值班核定、薪資、LINE 出勤班表的算法都不動
  • 薪資的跨店時數照舊由會計手填，自動加進新店不會改變薪資怎麼算
  • 各店打卡編號不換；打卡連結管理系統不存，要用時才即時跟打卡系統拿
  • 第一期的認領、登入、忘記密碼都不動

做之前要先處理的

  • 打卡系統的存檔正本落後線上版 26 處，先把線上版存回正本，免得一更新就洗掉保護
  • Mac mini 需要一個「定時做事」的小功能，要先跟維護 Mac mini 的同事確認（不同意也有替代做法）
  • 六家店的打卡系統各要設一把新的「給管理系統用的鑰匙」。這一步要你在 Google 編輯器貼上，到時候我會給逐步說明

回「規格 OK」（或指出要改的地方），我就排工作順序開始做。
