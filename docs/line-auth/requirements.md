# 需求：管理系統 LINE 認身分（核心＋B 重設密碼＋C 一鍵認領）
版本：v0.1 / 2026-10-25（待 Eason 確認）

## 1. 要解決的問題
- 管理系統 134 位同仁只有 7 位開通（2026-10-25）。認領要自己打編號、姓名、生日、手機等，門檻高。
- 開通後忘記密碼只能用「編號＋生日＋手機」重設；長期大家都會用管理系統，要一條更順的路。
- 已有 46 位同仁的打卡帳號綁了 LINE（六個有 LINE 打卡的點）。LINE 已經能證明「這支手機的主人＝打卡名冊上的某某」，佈告欄就是這樣自動登入的。

## 2. 使用者
- 有綁 LINE 打卡的同仁（小辛辣光復、墨竹亭金山／光復／六張犁、總部、央廚）。
- 審核認領的主管（店長、上一層主管、人資）——流程不變。
- 人資：處理對不上、冒用的例外。
- 沒有 LINE 打卡的門市（美村、南昌、一悟等）：照舊用生日＋手機，本案不影響他們。

## 3. 核心功能
### 核心：LINE 認身分
在 LINE 裡開一個小頁面 → LINE 交出「你是誰」的證明 → 後端找出這個 LINE 綁的打卡帳號 → 對到管理系統同仁（DZY 編號）。
- 一個 LINE 對到兩位不同同仁 → 拒絕、請找人資。
- 沒綁 LINE、或打卡帳號還沒對到管理系統 → 告訴同仁改用原本的方式，並說明找誰處理。

### B：LINE 重設密碼
已開通的同仁：LINE 認身分＋（加碼驗證，見問題 1）→ 設新密碼 → 其他裝置全部登出（同現在的忘記密碼）。

### C：LINE 一鍵認領
未開通的同仁：LINE 認身分 → 畫面帶出自己的姓名、單位、職稱 → 補填手機、生日、地址（見問題 3）→ 設密碼 → 送主管審核（同現在）。

### 不變的
生日＋手機重設、現有認領流程都保留；不推播任何 LINE 訊息；不改打卡系統的綁定規則（除非問題 1 選 c）。

## 5. 待 Eason 決定（最多 10 題，見網頁版）
1. B 的加碼驗證：a LINE＋生日（推薦）／b 只認綁定滿 7 天的 LINE／c 打卡綁定改成要店長確認

4. 入口：登入頁兩顆按鈕＋LINE 機器人打字（推薦）／也加進圖文選單（要換掉一格）

6. 這次順便做「用 LINE 直接登入」：不做（推薦）／做
